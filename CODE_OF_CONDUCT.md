# Code of conduct

This is a repository for a FiveM plugin that recolours street lights. The
rules are the ones you'd expect in any shared workspace.

- Be civil. Disagree with the code, not the person.
- Keep it on topic: the plugin, the game, the code.
- No harassment, no abuse, no posting anyone's personal details.
- Bug reports and pull requests get judged on their content; how long you've
  been around doesn't matter.

The maintainer decides what crosses the line, and may edit or remove comments,
close issues, or block accounts to keep the place usable. If something needs
raising privately, contact the maintainer through their GitHub profile.
